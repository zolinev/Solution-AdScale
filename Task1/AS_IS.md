# Анализ текущий архитектуры
1. Архитектура - монолит, нет возможности масштабирования отдельных компонентов
2. База данных - одна PostgreSQL, все модули работают с одной схемой, нет read-реплики, тяжелые аналитические запросы блокируют транзакционные
3. Отсутствие кеширования, каждый подбор кандидатов/аукцион/клик идет прямо в БД
4. Нет очередей, все операции синхронные, поэтому при пиковой нагрузке потоки исчерпываются/блокируются
5. Метрики - P95 уже 110-120мс при требовании не более 100мс уже сейчас при 15000 RPS. При увеличении нагрузки возможент нелинейный рост задержек
