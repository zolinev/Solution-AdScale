#Выбор архитектурного стиля

В условиях прогнозируемого роста нагрузки оставать в монолитном решении невозможно. Но и для перехода на микросервисы потребуется длительное время. 
Наилучшим подходом выглядит такой вариант:

Горизонт 3 месяца:

1. Выносим логику проведения аукциона в отдельный микросервис
2. Запросы от DSP-площадки через Gateway API маршрутизируем на этот новый сервис. Остальной функционал работает по-старому
3. Решаем актуальные проблемы с БД для поддеркжи 18К RPS
	4. Добавляем read-реплику к текущей БД
	5. Если не помогает, отделяем статистику и аналитику в отдельную БД

Горизонт 1 год:

 1. По мере готовности выносим функционал остальных модулей монолита в микросервисы (используем паттерн Strangler Fig)
 2. Добавляем кеш Redis, Кафку, разделяем БД per service
