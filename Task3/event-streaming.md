# Потоковая обработка данных

### Топики Кафка:

1. Топик кампаний - в него пишет Campaign Service по факту изменения/создания записи о кампании.  
2. Топик кликов и показов - в него пишет Delivery Service при показе/клике по  банеру. 
3. Топик балансов - в него пишет Financial Service при изменении баланса рекламодателя
4. Топик платежей - в него пишет Payment Service при успешном прохождении платежа. 
5. Топик заказов отчетов - в него пишет Advertiser Dashboard при запросе клиентом отчета
6. Топик уведомления о готовности отчетов - в него пишет Analitycs Service по факту готовности отчета

### Группы потребителей
Под каждый сервис, читающий Кафку, заводим свою consumer-группу. Таким образом:

1. при поднятии N инстансов одного сервиса сообщение в топике будет вычитано только единожды
2. одни и те же сообщения в одном топике будут вычитаны по одному разу каждой consumer-группой, т.е. разные сервисы смогут читать один и тот же топик

###Политика хранения
Для основных топиков - часы
Также необходимо создать топик для необработанных сообщений - в него сообщение записывается, если сервис-потребитель не смог его обработать. Для этого топика срок хранения - несколько дней/месяц, чтобы поддержка успела разобраться с проблемой
