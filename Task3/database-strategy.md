# Определите стратегию данных для каждого сервиса
Сервис - Тип базы данных - Обоснование

1. Сервис ставок - кеш Redis - большая нагрузка на чтение (кампании) и запись (победители аукционо), данные кампаний изменяются относительно редко
2. Сервис кампаний - Postgre - низкая нагрузка на чтение, низкая нагрузка на запись
3. Сервис статистики + сервис аналитики - ClickHouse - большая нагрузка на вставку + тяжелые аггрегационные запросы
4. Сервис финансов - Postgre - низкая нагрузка на чтение, низкая нагрузка на запись
